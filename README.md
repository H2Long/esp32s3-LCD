#在ESP32开发板上集成LCD屏幕

##概述

这是一个已经过验证的ESP32S3的最小系统板，目前第一版具有自动下载功能，引出所有IO引脚，同时集成了一个LCD接口。后续会加入SD卡，摄像头接口以及音频相关模块

##复刻建议

###First

本项目选用的USB转UART模块为CH340C,该芯片封装为，方便焊接但是体积占用大，可根据自己需要来选用不同芯片

###Second

本项目的LCD屏幕选用的是带电阻触摸，并焊接了XPT4056电阻触摸芯片，但是实测触摸并没有反应，目前还未排查原因

###Third

本项目选用鸿讯公司的18Pin的LCD屏幕，可根据自己的需要修改对应引脚
